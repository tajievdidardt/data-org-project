## Шаги
1. **Реестр источников S#.** Модули ERP/CRM и внешние источники кейса: тип данных (структ./полуструкт./неструкт.; колич./качеств.), формат, частота, есть ли ПДн.
2. **Открытые данные.** 1–3 реальных датасета (data.gov.ru / Росстат / data.europa.eu) для обогащения: зачем нужен, ссылка, оценка по 5-звёздочной модели. Существование проверить поиском.
3. **5V.** По строке на каждое V для кейса, с оценками-допущениями (объём, скорость обновления и т.д.).
4. **Модель данных.** Сущности E# (клиент, визит/заказ, услуга/товар, сотрудник, точка …), ключи, связи (ER-схема, можно Mermaid), что является мастер-данными («золотая запись»).
5. **Метрики → данные.** Для каждой M#: формула, из каких E#/S#, гранулярность. M# не считается из доступных данных — сразу скажи P1.
6. **Справочник ID.** Следишь, чтобы названия сущностей и источников были одинаковыми у всех.
