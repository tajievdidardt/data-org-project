# Проект «Организация данных» — эстафета на 1 день

Сдаём **отчёт 10–15 страниц + презентацию 7–10 слайдов**. Официальное задание лежит внутри каждого файла.

**Кейс (реальный):** Airbnb в Нью-Йорке. Закон Local Law 18 требует регистрации краткосрочной аренды; мы — офис Chief Data Officer, который проводит аудит данных объявлений на соответствие закону и предлагает программу качества данных.
**Данные (реальные, открытые):** Inside Airbnb (29 918 объявлений, 14.09.2026, CC BY 4.0) + официальный реестр регистраций мэрии NYC (02.11.2026). Всё лежит в `data/`: сырые файлы, очищенные, отчёт о качестве, ключевые цифры, графики и скрипт. Claude обязан считать по этим файлам, а не выдумывать.

Каждый следующий начинает, когда предыдущий написал в общий чат «готово». Цель — по 1,5 часа на шаг.

## Как работать (выбери один способ)
**А. Claude подключён к GitHub (лучше):** прими приглашение в репозиторий → в claude.ai Settings → Connectors подключи GitHub → в новом чате напиши:
> Я Артём (подставь своё имя). Подключи репозиторий tajievdidardt/data-org-project, прочитай CLAUDE.md и делаем мою часть.

Claude сам прочитает задание и разделы предыдущих, а готовый раздел сам сохранит в репозиторий.

**Б. Без GitHub:** скачай и прикрепи к новому чату: свой файл задания, готовые разделы предыдущих из `report/`, а также `data/processed/key_facts.md`, `data/processed/quality_report.md`, `data/processed/listings_clean.csv` и графики из `data/charts/` (открой файл на GitHub → «Download raw file»). Напиши «Делаем мою часть». Готовый текст отправь в общий чат, следующий прикрепит его своему Claude.

## Как выжать из Claude максимум
- **Один чат на всю свою часть.** Новый чат = Claude всё забыл.
- **Сначала черновик, потом правки.** Claude сразу выдаёт раздел целиком. Читай и правь точечно: «в таблице качества добавь актуальность», «сократи 1.1 вдвое».
- **Проси проверку.** В конце: «Проверь мой раздел по критериям задания и найди слабые места».
- **Факты — только с источниками.** Любая цифра должна быть помечена [данные: файл] или [источник: ссылка]. Нет пометки — спроси: «Откуда это? Посчитай по файлу».
- **Пусть Claude считает кодом.** «Посчитай по listings_clean.csv…», «построй график по…» — так результат реальный и проверяемый.
- **Готовься к защите сразу.** Последним сообщением: «Задай мне 5 каверзных вопросов комиссии по моему разделу и дай короткие ответы».
