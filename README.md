# Проект «Организация данных» — командный репозиторий

4 участника, 4 равные части, одна сквозная логика. Claude каждого участника получает общий контекст из `CLAUDE.md` и `00_brief/`.

## Кто что делает
| Часть | Кто | Что | Доп. роль |
|---|---|---|---|
| P1 — Проблема и логика | ___ | DECISION, SMART, логическая модель | собирает финал |
| P2 — Источники и модель данных | ___ | ERP/CRM/Open Data, 5V, ER-модель, формулы метрик | следит за ID |
| P3 — Архитектура и пайплайн | ___ | ETL/ELT, слои хранения, витрины, жизненный цикл, FAIR | главная схема |
| P4 — Управление и риски | ___ | DAMA, роли, качество, безопасность, культура, ISO 31000 | QA перед сдачей |

Твоё задание — `partN_*/TASK.md`. Пишешь в `partN_*/draft.md`.

## Порядок
1. **Кикофф (30 мин, все):** кто-то переносит официальные критерии со слайдов 4–7 в `00_brief/requirements.md`; выбираем кейс из `00_brief/case.md`; вписываем имена в таблицу выше.
2. **Дни 1–4:** работаем параллельно, передаём ID по графику в `00_brief/interfaces.md`.
3. **День 5:** P1 собирает `final/`. **День 6:** прогон.
Даты: день 0 = ___ , сдача = ___.

## Как подключить своего Claude
**Claude Code:** `git clone` → `cd` в папку → `claude`. `CLAUDE.md` подхватится сам. Первое сообщение: «Я P2, начинаем с TASK.md».

**claude.ai:** создай Project → в инструкции проекта вставь содержимое `CLAUDE.md` → в знания проекта добавь из GitHub только `00_brief/`, свою папку `partN_*` и `knowledge/course-kb.md`. Чужие папки не добавляй — это лишние токены.

## Как экономить лимиты
- Одна задача — один чат/сессия; в Claude Code между задачами `/clear`.
- Черновики — на Sonnet; Opus — для финальной проверки и сложных мест.
- Не вставляй в чат то, что уже лежит в репо, — пиши «см. interfaces.md».
- Сначала тезисы, оформление — один раз в конце.

## Git за минуту
```
git pull                    # перед началом работы
git add partN_*/ 00_brief/  # только своё
git commit -m "P2: источники S1–S5"
git push
```
Пишешь только в свою папку → конфликтов нет. В `00_brief/` правишь только свою таблицу. Не умеешь git — правь файлы прямо на github.com (карандаш ✏️).
