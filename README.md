# Проект «Организация данных» — эстафета на 1 день

Сдаём **отчёт 10–15 страниц + презентацию 7–10 слайдов**. Кейс (сеть салонов красоты «Бьюти-Лайн»), цели и общие ID уже решены. Официальное задание лежит внутри каждого файла.

## Очередь
| Шаг | Кто | Файл | Что делает | Пока ждёшь |
|---|---|---|---|---|
| 1 | Артём | `1_Artem.md` | разделы 1 и 2.1: состояние компании, SMART-цели, сбор данных | — |
| 2 | Женя | `2_Zhenya.md` | разделы 2.2, 2.3, 5: качество, хранение, логическая модель | заранее делает 2.3 |
| 3 | Гоша | `3_Gosha.md` | разделы 3 и 4: открытые данные, риски, этика, 152-ФЗ | заранее ищет датасеты и законы |
| 4 | Дидар | `4_Didar.md` | собирает отчёт, графики, выводы, презентацию, готовит защиту | заранее делает введение и шаблоны |

Каждый следующий начинает, когда предыдущий написал в общий чат «готово». Цель — по 1,5 часа на шаг.

## Как работать (выбери один способ)
**А. Claude подключён к GitHub (лучше):** прими приглашение в репозиторий → в claude.ai Settings → Connectors подключи GitHub → в новом чате напиши:
> Я Артём (подставь своё имя). Подключи репозиторий tajievdidardt/data-org-project, прочитай CLAUDE.md и делаем мою часть.

Claude сам прочитает задание и разделы предыдущих, а готовый раздел сам сохранит в репозиторий.

**Б. Без GitHub:** скачай свой файл (из Telegram или здесь: открой файл → «Download raw file») и готовые разделы предыдущих из папки `report/` → прикрепи всё к новому чату → напиши «Делаем мою часть». Готовый текст отправь в общий чат, следующий прикрепит его своему Claude.

## Как выжать из Claude максимум
- **Один чат на всю свою часть.** Новый чат = Claude всё забыл.
- **Сначала черновик, потом правки.** Claude сразу выдаёт раздел целиком. Читай и правь точечно: «в таблице качества добавь актуальность», «сократи 1.1 вдвое».
- **Проси проверку.** В конце: «Проверь мой раздел по критериям задания и найди слабые места».
- **Факты — только с источниками.** Если видишь цифру без «(допущение)» и без ссылки, спроси: «Откуда это?»
- **Готовься к защите сразу.** Последним сообщением: «Задай мне 5 каверзных вопросов комиссии по моему разделу и дай короткие ответы».

## Защита
Каждый рассказывает свои разделы (~2 минуты), Дидар открывает и закрывает. На вопросы по разделу отвечает его автор.
