# Как делаем проект

## Суть
Мы — дата-офис компании Airbnb. В Нью-Йорке закон обязывает регистрировать краткосрочную аренду. По реальным данным мы проверяем, насколько объявления соблюдают закон и насколько качественные данные, и предлагаем совету директоров план. Сдаём **отчёт на 10–15 страниц + презентацию на 7–10 слайдов**.

## Что где лежит
| Файл / папка | Что это | Нужно ли тебе открывать |
|---|---|---|
| `1_Artem.md` … `4_Didar.md` | Задание каждому: задание курса, кейс, цифры, что писать | Да, свой — его получает твой Claude |
| `CLAUDE.md` | Инструкция для Claude, он читает её сам | Нет |
| `data/processed/key_facts.md` | Главные цифры проекта | Да, полезно |
| `data/processed/quality_report.md` | Проверка качества данных | По желанию |
| `data/processed/listings_clean.csv` | Все 29 918 объявлений таблицей | Нет, это для Claude |
| `data/charts/` | 3 готовых графика для отчёта | Да |
| `data/raw/` | Исходные файлы, как скачали | Нет |
| `data/README.md` | Откуда данные и лицензии | Нет |
| `scripts/prepare_data.py` | Код, который очистил данные и посчитал цифры (доказательство, что всё реально) | Нет |
| `report/` | Сюда каждый кладёт готовый раздел, отсюда Дидар собирает отчёт | Да |
| `.github/` | Автоскачивание данных | Нет, не трогать |

## Алгоритм (каждому)
1. Прими приглашение на GitHub (письмо на почту или колокольчик на github.com).
2. claude.ai → Settings → Connectors → GitHub → подключи.
3. Открой новый чат и напиши: **«Я [имя]. Подключи репозиторий tajievdidardt/data-org-project, прочитай CLAUDE.md и делаем мою часть».**
4. Claude выдаст черновик твоего раздела. Прочитай и поправь точечно: «сократи 1.1», «добавь таблицу».
5. Проверь, что у каждой цифры стоит [данные: файл] или [источник: ссылка].
6. Напиши: «Проверь раздел по критериям задания» и исправь, что он найдёт.
7. Напиши «готово». Claude сам сохранит раздел в `report/`. Потом напиши «готово» в общий чат.
8. Для защиты попроси: «5 вопросов комиссии по моему разделу с ответами».

Если GitHub не подключается: прикрепи к чату свой файл задания, готовые разделы из `report/` и `data/processed/key_facts.md`, `quality_report.md`, `listings_clean.csv` (на GitHub открой файл → «Download raw file»). Готовый текст скинь в общий чат.

## Очередь
| Кто | Что пишет | Когда начинает | Что можно делать сразу |
|---|---|---|---|
| Артём | 1 (ситуация, цели) + 2.1 (сбор данных) | сейчас | — |
| Женя | 2.2 (качество) + 2.3 (хранение) + 5 (логическая модель) | после Артёма | 2.2 и 2.3 |
| Гоша | 3 (открытые данные) + 4 (этика, риски, право) | после Жени | 3 и 4.3 |
| Дидар | сборка отчёта, выводы, рекомендации, презентация, защита | после Гоши | введение, шаблоны, слайд «Команда» |

## Как разделы связаны
Артём ставит проблему и цели M1–M5 → Женя показывает, как данные проверяются, хранятся и как цели достигаются (логическая модель) → Гоша оценивает внешние данные, риски и закон → Дидар собирает всё в одну историю. Цифры M1–M5 у всех одинаковые.

## Правила
- Только реальные цифры: нет источника — нет цифры.
- Один чат на всю свою часть (новый чат = Claude всё забыл).
- Свой раздел — примерно 3,5 страницы.
- На защите каждый рассказывает свой раздел (~2 минуты).
