# Проект «Организация данных» — делаем за 1 день

Кейс уже выбран, общий скелет (метрики, данные, витрины) решён, официальные требования учтены. Поэтому все четверо начинают одновременно и никого не ждут.

## Кто что делает
| Файл | Часть | Кто |
|---|---|---|
| `P1.md` | Разделы 1 и 5: диагностика, SMART, логическая модель, мониторинг + собирает отчёт | ___ |
| `P2.md` | Раздел 2.1–2.2: сбор и обработка данных, качество | ___ |
| `P3.md` | Раздел 2.3 и 3: хранение, FAIR, открытые данные | ___ |
| `P4.md` | Раздел 4: риски, этика, право + делает презентацию | ___ |

Сдаём: отчёт 10–15 страниц + презентация 7–10 слайдов (по официальному заданию, оно внутри каждого файла).

## Что делать (каждому)
1. Скачай свой файл `P1.md`–`P4.md` (открой его → кнопка «Download raw file»).
2. Открой новый чат с Claude, прикрепи файл, напиши: **«Делаем мою часть»**.
3. Claude сразу выдаст черновик твоего раздела отчёта (~3 страницы). Поправь с ним то, что не нравится.
4. Отправь готовый текст в общий чат тому, кто делает P1.

## План на день
| Когда | Что |
|---|---|
| Старт | все делают свою часть со своим Claude (2–3 часа) |
| +3 часа | P2, P3, P4 отправляют свои разделы P1 (P3 — ещё лицензии датасетов P4) |
| +4 часа | P1 собирает отчёт и отдаёт P4 |
| +5 часов | P4 делает презентацию и проверяет, что всё сходится |
| Вечер | прогон защиты |

## Как экономить лимиты
- Один чат на всю свою часть, не начинай заново.
- Правки проси точечно: «перепиши слайд 3 короче», а не «переделай всё».
